# FalconCrypt 游戏功能文档

[项目说明](../README.md) | [English README](../README_en.md)

本文档仅聚焦游戏功能与规则本身，用于跨平台移植时的玩法对齐。

> 本文保留了跨平台规则约定，部分数值和交互尚未与当前 Web 版本同步。当前实现以 [`constants.ts`](../src/game/constants.ts)、[`state.ts`](../src/game/state.ts) 和[单元测试](../src/game/state.spec.ts)为准。

## 1. 核心体验

- 类型：终端文字冒险 + 轻度 Roguelike。
- 目标：探索 4 层地牢，逐层推进，击败最终 BOSS，获得鹰魂结晶。
- 体验循环：选角 -> 探索房间 -> 触发事件/战斗 -> 资源与成长结算 -> 继续推进。

## 2. 地图与关卡结构

### 2.1 层数与房间规模

- 总层数：4 层。
- 每层房间数依次为 4 / 5 / 6 / 7。
- 每层末尾房间固定为 BOSS 房。

### 2.2 房间类型池及权重

不同房间有不同生成权重，用数字表示：
- 怪物房：2
- 宝箱房：1
- 陷阱房：1
- 商人房：1
- 篝火房：1
- 铸锻房：1
- 雕像房：1
- 矿洞房：1
- BOSS房：不适用权重。每层末尾固定生成 BOSS 房。
- 分叉口：不适用权重。每层房间生成后随机替换 0~min(floor, 2) 个房间为分叉口。

### 2.3 地图信息和房间顺序

- 连续生成普通房间时，相邻的房间类型不能相同。
- 第 floor 层中，有 0~min(floor, 2) 个分叉口，玩家在 2/3 个分支中选择一个进入（同一分叉口绑下的房间类型强制两两不同），进入后随机判定，判定成功则刷新同层后续房间顺序并丢失已揭示信息。
- 玩家每进入一个房间，都有概率揭示同层下个房间（30%）和下层同个房间（10%），如房间1-2对应1-3（30%）、2-2（10%）。当被揭示房间为“分叉口”时，系统只会揭示其下属 2 或 3 个分支内随机一条路线的内容，其他选项依旧呈现“？”状。
- 游戏中始终显示地图面板，用于显示当前层和下一层的房间顺序，一个房间表示如“1-2 篝火”（已揭示）/“1-2 ？”（未揭示）。
- BOSS 房始终揭示。
- 术士技能可查看完整地图（增强路线规划能力）。

## 3. 属性与资源系统

### 3.1 玩家属性

- HP：生命值
- Coin：金币
- Def / Def Max：当前防御 / 最大防御
- Food：食物
- ATK Extra：额外攻击加成
- XP：经验进度
- XP Level：经验等级
- Scroll：当前持有卷轴（单槽）
- SP：战斗技能点

### 3.2 面板攻击显示

- 基础攻击范围由 XP 等级决定：
  - 最小值 = xp_level
  - 最大值 = 2 * xp_level + 4
- 若存在额外攻击加成，则在基础范围上叠加显示，如 xp_level=2 时显示“[2~6] +3”。

## 4. 角色系统

### 4.1 选角机制

- 每局选角阶段从角色池随机抽取 3 名候选角色供玩家选择 1 名。

### 4.2 角色与初始面板

字段顺序：名称, HP, Coin, Def Max, Food, ATK增益, 技能

- 术士：25, 8, 1, 9, 0, 神算
- 圣骑士：23, 5, 4, 9, 1, 净化
- 盗贼：24, 13, 1, 8, 0, 卷轴
- 祭司：30, 7, 1, 8, 0, 血祭
- 刺客：22, 4, 1, 7, 2, 挑衅

Def 初始化为 Def Max。

### 4.4 角色技能

- 通用-暴击：战斗时可用，随机使本次攻击伤害变为 0.25/0.5/1.5/2/2.5 倍，SP 消耗 3。
- 术士-神算：始终显示完整地图。
- 圣骑士-净化：战斗时可用，立即消耗 Food -n，随机使怪物攻击 -n~-(n+1)，SP 消耗 4。
- 盗贼-卷轴：初始时和击败每层 Boss 后获得随机卷轴。
- 祭司-血祭：战斗时可用，以 HP -3~-5为代价随机获得临时的 ATK Extra +1~+3，战斗结束后扣除，SP 消耗 6。
- 刺客-挑衅：战斗时可用，以 怪物攻击 +1~+2 为代价随机获得临时的 ATK Extra +2~+4，战斗结束后扣除，SP 消耗 4。

## 5. 战斗功能规则

### 5.1 回合框架

- 玩家回合可执行：普通攻击、角色技能、卷轴（若持有）。
- 注意：角色释放**技能**或使用**卷轴**均为不消耗回合的瞬发动作，可以连招。（仅普通攻击会消耗回合进度。）
- 玩家确认发动普通攻击动作后进入怪物回合（对方被冻结等特例除外）。而且每次开始新的攻击回合时，自动清空上一回合的无关战斗日志。

### 5.2 普通攻击

- 玩家伤害 = 随机基础伤害 + 额外攻击。
- 随机基础伤害范围：xp_level ~ (2 * xp_level + 4)。

### 5.3 怪物攻击

- 低攻怪（atk < 4）：固定伤害。
- 高攻怪（atk >= 4）：在基值附近小幅波动（-1 到 +1）。

### 5.4 技能点机制

- 数据面板仅在战斗时显示 SP 数据。每场战斗初始 SP = 12。
- 每次释放角色技能需要消耗 SP。
- SP 不足时不能释放技能（“使用技能”按钮变灰）。

### 5.5 战斗胜负

- 怪物 HP <= 0：战斗胜利。发放与当前层数成正比的随机数经验（XP保护规则）。若击败本层关底 BOSS ，则额外在胜出后直接刷新出一个富含极品奖励的宝箱房（必然触发额外奖励选项）作为通关补给点。
- 玩家 HP <= 0：游戏失败。

## 8. 卷轴系统

### 8.1 卷轴清单

- 火球术：造成额外伤害 9~14。
- 寒冰术：冻结敌人一回合（跳过怪物本回合行动）。
- 治疗术：恢复 9~13 HP，HP>10 时恢复 4~7 HP。
- 隐身术：直接离开非 Boss 战斗。

### 8.2 持有与使用

- 卷轴为单槽位道具，同一时间仅可持有 1 张，发生替换时询问用户。
- 卷轴仅在战斗中使用，使用后立即结算效果并消耗。

## 9. 房间事件功能清单

### 9.1 怪物房

- 交互：（战斗前）进入战斗按钮；（战斗时）攻击按钮/技能按钮/使用卷轴按钮。
- 功能：触发战斗。
- 怪物池：蜘蛛、毒鼠、骷髅、灵卫、狼人、巨魔、虫群。（TODO：补充怪物专属特性，如怪物先手、玩家减益）
- 怪物面板：
  - 基础生命约为 floor*4+2~5，并按怪物类型做增减。
  - 基础攻击约为 floor+1~2，并按怪物类型做增减。
- 核心意义：主要经验与资源风险来源。

### 9.2 宝箱房

- 交互：打开宝箱按钮。
- 奖励条目数：1~4 项。
- 宝箱奖励池：
  - 金币：+2~8
  - 浑浊的药水
  - 生命药水
  - 磨刀石
  - 劣质护甲板
  - 优质护甲
  - 卷轴：随机获得 1 种（单槽替换）
- 同一宝箱内奖励不重复。
- 核心意义：正向奖励点。

### 9.3 陷阱房

- 交互：解除陷阱按钮（大概率触发陷阱，但成功解除可获取资源） / 强行通过按钮（中概率触发陷阱）。
- 陷阱类型池（后附对应解除陷阱奖励）：
  - 火焰：真实伤害（无视护甲）[奖励：卷轴-火球术]
  - 酸雾：仅腐蚀护甲（清空当前 Def）[奖励：磨刀石]
  - 落石：造成 HP 伤害 [奖励：金币+3~6]
  - 尖刺：造成更高 HP 伤害 [奖励：食物+2~4/优质护甲]
- 触发陷阱后 50% 概率获得补偿收益（XP+1~3）。
- 核心意义：高风险突发损耗点。

### 9.4 商人房

- 交互：购买商品（显示商品列表，用户点击列表项购买） / 离开按钮。
- 每次进入随机上架 6~9 件商品。
- 商店商品池（买入）：
  - 小生命药水：-3 Coin
  - 大生命药水：-5 Coin
  - 磨刀石：-4 Coin
  - 劣质护甲板：-4 Coin
  - 护甲片：-6 Coin
  - 金币袋：-3 Coin
  - 小份干粮：-3 Coin
  - 大份干粮：-6 Coin
  - 卷轴：-6 Coin，已有卷轴时不可购买
- 商店商品池（卖出）：
  - 出售护甲片
  - 出售食物
  - 出售卷轴
- 不可购买/出售时会在按钮上显示原因（如金币不足、无卷轴）。
- 核心意义：把金币和战力与生存资源互相转化。

### 9.5 篝火房

- 交互：治疗按钮 / 加工食物按钮 / 打磨武器按钮 / 搜索按钮。
- 固定四选一：
  - 治疗：HP+2~6
  - 加工食物：Food+1~4
  - 打磨武器：ATK Extra 变化（常见为+1，也可能-1/+2）
  - 搜索：随机触发 1~3 个分支事件
- 搜索分支池：
  - 找到食物：Food+4~7
  - 找到金币：Coin+3~9
  - 遭遇怪物：进入战斗（弱化怪，约 HP8~12 / ATK1~4）
- 核心意义：恢复与中期运营节点。

### 9.6 铸锻房

- 交互：升级武器按钮 / 锻造护甲按钮。
- 选项与价格：
  - 升级武器（4 Coin）：ATK Extra 变化（常见为+1，也可能-1/+2）
  - 锻造护甲（5 Coin）：Def Max+1
- 护甲上限：Def Max 达到 7 后，无法使用锻造护甲。
- 金币不足时对应选项不可用。
- 核心意义：面板成长与防线强化。

### 9.7 雕像房

- 交互：祈祷按钮 / 供奉按钮。
- 祈祷结果：
  - 常规祈祷：约 40% 概率祝福，60% 概率诅咒
  - 供奉祈祷：约 90% 概率祝福，10% 概率诅咒
- 供奉成本：优先消耗 3~5 Coin；若无金币则消耗 1 Food；两者都无则供奉不可用。
- 祝福池：
  - HP+2~5
  - Def+2~6
  - ATK Extra+1
  - XP+1~3/(小概率+8)
- 诅咒池：
  - 真实伤害 HP-2~5
  - XP-1
- 核心意义：高波动增益或代价型决策点。

### 9.8 矿洞房

- 交互：挖掘按钮，每次先消耗 1 Food（Food<=0 时可选真伤消耗生命值进入）/离开按钮。
- 挖掘结果池：
  - 宝箱（约 20%）：触发一次宝箱奖励
  - 罕见矿石（约 10%）：ATK Extra+1 或 Def Max+2
  - 普通矿石（约 30%）：Coin+3~8
  - 矿洞植物（约 20%）：Food+1~3 且 HP+2~5
  - 遭遇幼年岩虫（约 10%）：进入战斗
  - 废石（约 10%）：仅消耗食物
- 核心意义：以消耗换收益的资源博弈点。

### 9.9 BOSS 房

- 交互：进入 BOSS 战按钮。
- 固定 BOSS（按层）：
  - 1 层：巨型蜘蛛
  - 2 层：蟒
  - 3 层：重甲骷髅
  - 4 层：地狱犬
- 动态强度：2~4层 Boss 会结合玩家当前成长状态做动态校准（HP/ATK）。
- 核心意义：层级终局挑战与进度门槛。

## 10. 房间后结算规则

每次完成房间交互后，执行一次通用结算：

1) 经验升级

- 每 8 点 XP 提升 1 级。
- 溢出经验保留到下一级进度。

2) 防御自然恢复

- 每房间恢复 1 点 Def，最高不超过 Def Max。

3) 食物与生命联动

- 有食物：消耗 1 食物并恢复生命（2 ~ floor+2）。
- 无食物：受到饥饿伤害（1 ~ floor+2）。

## 11. 功能对齐检查表

- 地图规模是否为 4 层且房间递增 4/5/6/7。
- 普通房间是否遵循权重分布。
- 角色池、初始属性、职业技能标签是否一致。
- 战斗伤害公式、SP 规则、回合顺序是否一致。
- 卷轴四类效果与单槽替换逻辑是否一致。
- 房间后结算（升级/防御恢复/食物联动）是否一致。
- 胜负判定与流程跳转是否一致。
